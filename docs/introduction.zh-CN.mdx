# Headplane 是什么？ [#what-is-headplane]

[Headscale](https://headscale.net) 是 Tailscale 控制服务器的自托管实现，使 Tailscale 客户端能够在不使用 Tailscale 服务器的情况下组成专用网络。Headscale 本身不提供 Web 界面；Headplane 为它提供了一个参考 Tailscale 管理控制台设计的 Web 界面。

Headplane 可以管理：

- **设备**：重命名、更换所有者、批准子网路由和出口节点、管理标签，以及使设备过期或移除设备。
- **用户和认证密钥**：包括每个人在 Headplane 中的操作权限。
- **访问控制**：通过可视化界面或文件编辑 ACL 策略。
- **DNS**：tailnet 名称、Magic DNS、DNS 服务器、搜索域和解析记录。

Headplane 还补充了 Headscale 本身没有的功能：

- 通过任意 OpenID Connect 提供商或反向代理实现**单点登录**，并为每个人分配角色。
- 无需安装客户端，即可通过**浏览器 SSH** 连接 tailnet 内的设备。
- 使用 **Headplane Agent** 显示每台设备的 Tailscale 版本、操作系统和连接状态。
