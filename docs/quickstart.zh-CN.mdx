# 快速开始 [#quickstart]

本指南从零部署完整服务：在同一个 Compose 项目中运行 Headscale、Headplane 和 Caddy，共用一个域名。Caddy 处理 HTTPS，Headplane 位于 `/admin` 路径下，并可修改 Headscale 的设置，包括 DNS。

已有 Headscale 时，直接参阅[安装](/install)。

:::note[双语版本发布状态]
以下示例沿用上游已发布的镜像。社区双语稳定镜像为 `ghcr.io/laity-cqf/headplane-zh-cn:v0.8.2`，对应 `stable` 及其随版本文档；上游镜像不包含本仓库的中文界面。双语发布与部署进度见[语言与维护说明](/features/language)。
:::

## 前提条件 [#requirements]

- 已安装 Docker 和 Docker Compose 的 Linux 服务器。
- 指向该服务器的域名，以下使用 `headscale.example.com`。
- 开放 80 和 443 端口，以便 Caddy 申请证书。

## 1. 获取 Headscale 配置 [#1-get-headscales-config]

下载 Headscale 示例配置，并创建一个空的 DNS 记录文件：

<DynamicCodeBlock lang="bash" code={quickstartFetch} />

修改 `headscale/config.yaml` 中的以下字段：

```yaml
server_url: https://headscale.example.com
listen_addr: 0.0.0.0:8080

policy:
  # 将 ACL 策略存入数据库，以便 Headplane 编辑
  mode: database

dns:
  # 不能使用服务器自身的域名，也不能使用其上级域名（例如 example.com）
  base_domain: tailnet.example.com
  extra_records_path: /etc/headscale/extra-records.json
```

## 2. 配置 Headplane [#2-configure-headplane]

运行 `openssl rand -hex 16` 生成 Cookie 密钥，并将以下内容保存为 `headplane/config.yaml`。将占位值替换为命令输出：

```yaml
server:
  base_url: "https://headscale.example.com"
  cookie_secret: "<output of openssl rand -hex 16>"

headscale:
  url: "http://headscale:8080"
  public_url: "https://headscale.example.com"
  config_path: "/etc/headscale/config.yaml"

integration:
  docker:
    enabled: true
```

`url` 是 Headplane 在 Docker 内访问 Headscale 的地址；`public_url` 是向接入设备的用户显示的地址。配置 `config_path` 并启用 Docker 集成后，Headplane 可以编辑 Headscale 设置，然后重启 Headscale 使其生效。

## 3. 使用 Caddy 转发请求 [#3-route-traffic-with-caddy]

将以下内容保存为 `Caddyfile`：

```caddyfile
headscale.example.com {
    redir / /admin/

    handle /admin* {
        reverse_proxy headplane:3000
    }

    handle {
        reverse_proxy headscale:8080
    }
}
```

将以下内容保存为 `compose.yaml`：

两个容器将 `headscale` 文件夹挂载到相同路径，因此 Headplane 编辑的正是 Headscale 读取的文件。容器标签使 Headplane 能通过 Docker socket 找到 Headscale 容器。

```bash
docker compose up -d
```

## 5. 登录 [#5-sign-in]

创建用于登录的 API 密钥：

```bash
docker exec headscale headscale apikeys create --expiration 90d
```

打开 `https://headscale.example.com/admin`，粘贴该密钥。

## 6. 添加设备 [#6-add-a-machine]

先在**用户**页面为设备所有者创建用户，再在**设备**页面选择**添加设备**：

- **注册设备密钥**：输入设备运行 `tailscale up --login-server https://headscale.example.com` 后显示的密钥。
- **创建认证密钥**：生成可直接用于加入网络的密钥，然后运行 `tailscale up --login-server https://headscale.example.com --auth-key <key>`，省去交互注册步骤。
