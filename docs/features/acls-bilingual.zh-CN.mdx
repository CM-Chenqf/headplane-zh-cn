本页介绍 `laity-cqf/headplane-zh-cn` 的 `main` 分支。开发分支不发布 Docker 镜像；部署使用稳定版 `v0.8.2-zh` 及镜像标签 `v0.8.2`。发行说明见[语言与维护说明](/features/language)。

### 权限与策略存储

在顶部选择 **简体中文**，打开 **访问控制**。
所有者、管理员和网络管理员可以编辑策略；有读取权限但无写入权限的角色只能查看。
只有 Headscale 的策略处于 `database` 模式时才能通过面板保存：

<span id="configuration-examples" />

```yaml
# Headscale config.yaml
policy:
  mode: database
```

`file` 模式保持只读。按 Headscale 的配置要求应用模式更改后，再返回面板编辑。
文件模式下若配置的策略文件不存在，页面会说明创建文件或切换存储模式的方法。
连接失败时显示错误及重试入口，不会把已有策略当成空策略。

<span id="rules-tags-and-groups" />

### 编辑规则

**规则**选项卡包含以下列表。每项可添加、编辑或删除；弹窗中的更新仅修改浏览器内草稿，
点击页面底部的 **保存** 后才会提交到 Headscale。

| 列表               | 策略字段        | 说明                                                                                       |
| ------------------ | --------------- | ------------------------------------------------------------------------------------------ |
| 访问规则           | `acls`          | 设置来源、目标和可选协议。目标需包含端口，如 `tag:web:80,443`；未填写端口时自动补上 `:*`。 |
| 授权规则（Grants） | `grants`        | 来源、目标、端口与协议分别设置；目标不带端口，协议示例为 `tcp:443`。                       |
| SSH 规则           | `ssh`           | 设置来源、目标、本地 Unix 用户，以及直接允许或定期重新认证。                               |
| 主机别名           | `hosts`         | 为 IP 或 CIDR 网段设置可在规则中引用的名称。                                               |
| 自动批准者         | `autoApprovers` | 按用户、用户组或标签自动批准设备通告的子网路由、出口节点。                                 |

授权规则需要 Headscale {versions.headscale.grants} 或更新版本，旧版本隐藏此列表，
服务端也会拒绝绕过界面提交不受支持的 `grants` 配置。
**经由节点**仅接受子网路由器或出口节点的标签；使用出口节点时，目标设为 `autogroup:internet`。
已有 `app` 应用能力会保留，但需要在文件中修改。

SSH 规则中的 `accept` 表示直接允许，`check` 要求定期重新认证；重新认证周期示例为 `12h`。
界面只翻译已知操作的说明。未知操作保留原始值，不会被替换为允许访问。
主机别名只允许小写英文字母、数字和连字符；路由应使用有效 IPv4 或 IPv6 网络前缀。

### 标签与用户组

打开 **标签与用户组**：

1. 在用户组或标签列表点击 **添加**。
2. 输入符合 `group:...` 或 `tag:...` 格式的名称。
3. 选择建议项，或输入成员、标签所有者后点击 **添加**。
4. 提交弹窗，再检查草稿并点击页面底部的 **保存**。

名称前缀之后只允许小写英文字母、数字和连字符。重复名称会显示提示并阻止提交。
用户引用按上游格式使用 `username@`；标签所有者可包含用户和用户组。
列表同时显示标签当前分配给哪些设备。设备上未声明的标签仍需在策略 `tagOwners` 中声明后才可匹配规则。
重命名或删除条目后，检查其他规则对旧名称的引用。

用户组成员也可从[用户管理](/features/users-bilingual)中编辑，两处使用同一个策略字段。

<span id="file-editing-and-saving" />

### 编辑文件与预览更改

**编辑文件**打开 HuJSON 编辑器；**预览更改**对比草稿和已保存策略。
两个入口与可视化编辑共用同一份草稿。**放弃更改**将草稿恢复为服务器返回的策略。

编辑器状态、语法错误、行列位置、格式化按钮，以及查找、替换、跳转、折叠等编辑器提示支持中英文。
切换语言不会重写策略内容。文件、规则字段、用户名称、CIDR、端口、标签和协议等标识保留原文。
存在本地语法错误时禁用保存；Headscale 返回的校验错误保留原始诊断，附中文说明与 HTTP 状态。
Headscale 拒绝保存时，原策略保持不变。

**格式化**使用两空格缩进，保留注释、已有换行和尾随逗号。
通过可视化编辑器修改策略则会重新生成文本并移除注释；页面会显示警告。
需要保留注释时，在文件编辑器中操作。
可视化编辑器不识别的顶层字段（如 `nodeAttrs`、`tests`）以及规则中的额外字段按上游方式保留。

**预览规则**仍是上游尚未实现的功能，只显示不可用说明，不会模拟网络访问结果。
访问策略的实际结果应以 Headscale 和设备行为为准。
