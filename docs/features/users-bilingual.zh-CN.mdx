# 用户操作指南

### 区分账号与用户

- **Headplane 账号**用于登录面板，首次通过 SSO 或代理认证登录时创建。角色决定面板内的操作权限。
- **Headscale 用户**拥有设备和认证密钥。账号关联某个 Headscale 用户后，才能识别属于自己的设备和密钥。
- **未关联的 Headscale 用户**尚未关联任何 Headplane 账号，可以先创建，之后再关联。

每个账号可关联一个 Headscale 用户，同一个 Headscale 用户不能同时关联多个账号。
Headplane 在登录时，以及未关联账号再次打开页面时，尝试按 SSO subject 或邮箱自动匹配尚未被关联的用户。
Headscale 也启用 SSO 时，首台设备登录后可能完成自动关联。详细匹配条件见
[SSO](/features/sso#how-accounts-match-headscale-users)。

### 查看用户

在顶部选择 **简体中文**，打开 **用户**。账号表格显示角色、最近登录和设备最近在线时间。
“未关联”表示账号尚未建立 Headscale 关联；“暂无设备”表示当前数据中未找到该用户的设备。
Headscale API 不可达时，面板仍显示本地 Headplane 账号，同时提示无法获取 Headscale 用户及设备信息。
此时不显示用户组编辑入口。

<span id="create-rename-and-delete" />

### 创建、重命名与删除

1. 选择 **添加用户**。
2. 输入用户名，可选填显示名称和电子邮箱。
3. 点击 **创建用户**。新用户先进入“未关联的 Headscale 用户”列表。
4. 需要时，在未关联用户的操作菜单中选择 **重命名** 或 **删除**。

用户名至少为 2 个字符，以字母开头，仅包含字母、数字、点、连字符和下划线，
最多有一个 `@` 且不能以其结尾。规则支持 Unicode 字母和十进制数字，不限于英文字母。
重命名不会自动修改 ACL 中引用的旧用户名。由 OIDC 管理的用户不提供重命名操作。

删除前先移除设备或更改设备所有者。删除无法撤销；由 OIDC 管理的用户再次登录时会被重新创建。
删除 Headscale 用户会解除相关账号的关联，不会删除 Headplane 登录账号。
当前账号的行菜单不提供删除其关联用户的操作。

### 关联账号

所有者、管理员和 IT 管理员可以执行以下步骤：

1. 在 Headplane 账号行的操作菜单选择 **关联 Headscale 用户**。
2. 选择尚未被其他账号关联的 Headscale 用户，点击 **关联用户**。
3. 已有关联时，选择 **更改关联用户**；选项中的“当前关联”标记现有选择。

没有可用用户时，先创建 Headscale 用户。若其他管理员已抢先关联所选用户，提交会被拒绝，并提示重新选择。
关联用户决定“自己的设备和密钥”归属，操作范围仍受角色权限限制。

拥有用户管理权限的账号在 SSO 登录后未能自动匹配时，会看到 **关联账号** 页面。
选择自己的用户，或点击 **暂时跳过**，之后从用户页完成关联。其他角色不能自行选择任意用户，
需要自动匹配或由管理员关联。

### 角色与所有权

首次登录者成为唯一所有者。之后的新账号默认是成员；SSO 可另行配置初始角色或使用身份提供商声明。
角色权限与上游一致，以下名称仅随显示语言变化，内部角色标识保持不变。

| 角色       | 权限范围                                                      |
| ---------- | ------------------------------------------------------------- |
| 所有者     | 所有权限，包括转移所有权；实例只有一名所有者。                |
| 管理员     | 除转移所有权外的全部管理权限。                                |
| 网络管理员 | 管理 ACL、DNS 和网络设置；查看设备和用户；创建认证密钥。      |
| IT 管理员  | 管理设备、用户、设置和登录限制；可查看但不能修改 ACL 和 DNS。 |
| 审计员     | 查看全部管理页面，为自己创建认证密钥。                        |
| 查看者     | 查看设备和用户，为自己创建认证密钥。                          |
| 成员       | 不可访问管理控制台，显示设备接入首页。                        |

在已关联账号的操作菜单中选择 **更改角色**，选择角色并提交。
所有者不能通过普通角色调整变更，只能由当前所有者选择其他账号的 **转移所有权**。
转移成功后原所有者成为管理员，仅新所有者可以再次转移。
API 密钥登录拥有上游规定的完全访问权限，但不代表某个账号所有者，因此不能转移所有权。

### 用户组

同时拥有用户管理和 ACL 策略写入权限，且 Headscale 策略处于可写的 `database` 模式时，
关联用户或未关联用户的操作菜单会提供 **编辑用户组**。

1. 选择已有 `group:...` 用户组，或输入符合上游规则的新组名。
2. 添加或移除成员资格。
3. 点击 **保存用户组**。

用户组存储在 ACL 策略的 `groups` 字段。保存会重写策略，保留其他成员；若策略有注释，
界面会警告保存将移除注释。文件模式为只读；需要编辑时，在 Headscale 配置中将
`policy.mode` 设为 `database`，并按 Headscale 的配置要求使其生效。
仅修改显示语言不会修改策略。

### 成员接入设备

没有管理控制台权限的成员登录后会看到 **连接设备** 首页：

1. 按平台下载 Tailscale；Linux 可使用页面提供的安装脚本。
2. 运行页面提供的 `tailscale up --login-server=...` 命令，或在客户端配置同一协调服务器。
3. 按页面提示等待 SSO 自动关联，或联系管理员关联账号、批准新设备。

页面分别显示已关联、等待首台设备或需要联系管理员的状态。安装链接、服务器地址和命令保留原文。
成员接入流程不会授予管理控制台权限。
