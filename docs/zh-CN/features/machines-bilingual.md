# 0.8 双语发布线的设备管理

[English](/features/machines-bilingual)

本指南适用于基于 [tale/headplane](https://github.com/tale/headplane) 的非官方维护仓库 `laity-cqf/headplane-zh-cn` 的 `stable` 分支，说明原有 0.8 界面的操作。其他业务模块和完整文档仍在适配中，当前不能称为完整汉化发行版。进度见[语言与发布线维护](/zh-CN/features/language)。

## 选择语言 {#choose-a-language}

使用管理界面顶部的语言按钮。设备列表、详情、筛选、菜单、注册及管理弹窗、校验消息、本地操作结果、状态徽标和日期均跟随英文或简体中文。切换语言保留当前 URL、搜索词及筛选值。

设备名、所有者、ACL 标签、IP 地址、域名、密钥、版本及设备上报的操作系统名称保留原值。命令以及 SSH、IPv4、IPv6 等协议名称不翻译。缺少设备信息时，根据语言显示“未知”或“Unknown”。

## 查找和查看设备 {#find-and-inspect-a-machine}

打开**设备**，按名称或 IP 地址搜索，按用户、标签、连接状态或路由类型筛选，并按名称、地址、版本或最后在线时间排序。筛选保留 `online`、`exit-node` 等原始查询标识，只翻译显示标签。与上游 0.8 一致，版本列是否显示取决于 Agent 是否可用。

点击设备名称，可查看所有者、路由、标识符、地址、创建时间及密钥过期时间。Agent 信息可用时，还会显示操作系统及 Tailscale 版本、端点和连接详情。绝对日期与相对时间按所选语言格式化，相对时间沿用 0.8 的分钟、小时、天和每月 30 天的计算阈值。

使用地址菜单复制 IP 地址或 MagicDNS 名称，复制成功及失败提示跟随界面语言；MagicDNS 名称及复制内容保持原值。

## 注册设备 {#register-a-device}

1. 选择**添加设备 → 注册设备密钥**。
2. 在设备上运行弹窗中显示的命令：

   ```bash
   tailscale up --login-server=<headscale-public-url>
   ```

3. 粘贴命令输出的设备注册 URL 或完整的 `hskey-authreq-...` 密钥。
4. 选择所有者并确认注册。

服务器地址来自现有 Headscale 配置。所选所有者仍按 0.8 注册 API 的要求提交原始用户名。API 密钥和预认证密钥均不是设备注册密钥，无效输入会在注册前被拒绝。

**生成预认证密钥**会打开现有设置页面。设置模块不在本阶段范围内，仍可能显示英文。

## 管理设备 {#manage-a-device}

设备行菜单或**设备设置**包含原有操作。控件是否可用继续取决于权限、设备状态及连接的 Headscale 版本。

| 操作               | 行为                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 编辑设备名称       | 使用最多 63 个字符的有效 DNS 标签，仅含英文字母、数字和连字符，且以字母或数字开头和结尾。MagicDNS 提示会说明名称变化。 |
| 启用或禁用密钥过期 | 仅在现有 Headscale 能力支持时显示，成功提示对应实际选择的设置。                                                        |
| 编辑路由设置       | 批准或撤销已通告的子网路由及出口节点用途，设备需先通告相应路由。                                                       |
| 编辑 ACL 标签      | 添加或移除原始 `tag:...` 值。未在 `tagOwners` 中声明的标签会显示中文警告，并提供访问控制链接。                         |
| 更改所有者         | 仅在 Headscale 版本支持现有所有者变更 API 时显示。                                                                     |
| 立即使密钥过期     | 沿用原有过期操作，使设备断开连接，直到在设备上重新认证。                                                               |
| 移除               | 确认后将设备移出网络，重新加入需要在设备上认证。                                                                       |

读取不到策略时，ACL 标签弹窗不会把所有标签都标为未声明。Headscale 拒绝更新时，中文说明会保留 HTTP 状态及原始诊断详情；原始 API 错误仍可用于排查问题。

SSH 入口保留原有连接行为，浏览器 SSH 本身将在后续阶段汉化。语言切换不会授予当前角色原本不具备的操作权限。

## 维护与发布 {#maintenance-and-publication}

已完成的设备源码及本组中英文文档纳入发布线翻译检查。上游修改这些文件后，需同时核对文案与实际行为，再记录新的复核指纹。

运行 `pnpm i18n:check`、`pnpm test:unit`、`pnpm typecheck` 和 `pnpm docs:build`。路由或操作变更还需运行现有集成测试。VitePress 根路径及 `/0.8/` 归档分别构建，不引入 `main` 的新版文档工具链。

其他模块和发布验收完成前，完整发行版检查继续阻止发布。本阶段不发布 Docker 镜像，也不部署文档站。现有截图仍为上游英文界面示意，不是本汉化版本的截图。
